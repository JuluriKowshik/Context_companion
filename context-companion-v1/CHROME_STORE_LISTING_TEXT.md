# Context Companion: Chrome Web Store Listing Text

## Short description

A quiet companion for YouTube that explains genuinely useful terms while you watch, without interrupting the video with noisy or low-value content.

## Full description

Context Companion helps you understand unfamiliar terms while watching YouTube videos. It watches subtitle timing, identifies genuinely useful or uncommon concepts, and shows a small explanatory card only when the term is relevant.

It stays quiet when a word is not worth interrupting the video for. The extension is designed to be helpful without becoming distracting.

Features:

- watches YouTube caption timing automatically
- explains useful terms at the moment they are spoken
- avoids low-value or noisy interruptions
- keeps a short local state so repeated explanations are controlled
- works through a lightweight backend API so the AI key stays on the server
- designed to preserve the normal YouTube viewing experience

Privacy:

The extension reads caption text and nearby context to identify educational or unfamiliar terms. This information is sent to the backend for processing. The backend may call an external AI provider to generate an explanation. The extension does not require users to enter their own AI API key.

This extension is intended for learning and comprehension while watching educational or informational YouTube videos.
